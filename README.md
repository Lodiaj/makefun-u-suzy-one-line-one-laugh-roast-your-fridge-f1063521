One line roasting my fridge, written by a small program. `main.ts` writes a
single line to `/output/entry.txt`.

The roast:

> My fridge's crisper drawer is where vegetables go to file for retirement — nothing comes out crisp, everything comes out tired.

## Run

```sh
node main.ts
```

It writes the roast to `/output/entry.txt` (1–200 characters, a single line).
